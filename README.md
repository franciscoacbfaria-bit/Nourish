# Nourish

A private nutrition and wellness tracker that runs entirely in the browser.

- Meals, food encyclopedia (values per 100 g), photo journal, weekly activity, history and trends
- Daily calorie limits from sex, age, height, weight and daily life, plus each weekday's estimated burn:
  rest days 300 kcal below maintenance, training days 200 kcal above
- Teen mode (13–17): growth-inclusive energy needs, no decrease on rest days
- Built-in assistant for help and app settings
- Works offline and installs to the home screen (Add to Home Screen)

All data stays in the browser's local storage on each device. Use **Settings → Export full backup** to keep a copy.

Nourish gives general wellness estimates and is not medical advice.
